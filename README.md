NUSA SENJA — a travel poster for a place that does not exist. A fictional island at golden hour: a volcano on the horizon, a tiered temple on a terraced hill, a lagoon with a lone sailboat, and a stone gate framing the view. Drawn in the vintage Indonesian travel-poster style of Yogyakarta and Bali — flat bold shapes, layered mountain silhouettes, a big sun, warm sunset palette (deep teal, sunset orange, cream, maroon).

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
```

Writes `entry.png` (1024x1024, deterministic, byte-identical across runs) to the output directory. Python 3.13, standard library only — the program draws every pixel itself with its own PNG encoder and a bitmap font defined in code.
